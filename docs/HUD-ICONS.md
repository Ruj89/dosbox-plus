# Icone dei pulsanti HUD

Le 12 icone in `app/src/main/res/drawable/hud_*.xml` sono adattamenti in Android Vector Drawable delle **Material Icons** di Google, disponibili con licenza [Apache 2.0](https://github.com/google/material-design-icons/blob/master/LICENSE). Non sono disegnate per questo progetto.

Sorgente: [google/material-design-icons](https://github.com/google/material-design-icons/tree/master/src), variante `materialicons/24px.svg`. Corrispondenze:

| File HUD | Icona originale |
| --- | --- |
| gamepad | social/sports_esports |
| fire | image/flash_on |
| run | maps/directions_run |
| bolt | content/bolt |
| map | maps/map |
| shield | content/shield |
| rocket | action/rocket_launch |
| star | action/stars |
| eye | action/visibility |
| night | social/nights_stay |
| save | content/save |
| mouse | hardware/mouse |

Sono stati convertiti esclusivamente i tracciati SVG in path Android. Le immagini personali scelte nell'editor vengono ridimensionate e incorporate nel JSON del profilo, quindi funzionano anche dopo un'esportazione o un'importazione.
